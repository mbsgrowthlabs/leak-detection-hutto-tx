# Leak Detection Hutto TX — GitHub Pages Article

A simple, responsive HTML/CSS article about identifying hidden plumbing leaks in Hutto, Texas. It includes SEO metadata, Open Graph tags, Article and FAQ structured data, clear navigation, and links to https://leakdetectionhuttotx.com/.

## Files
- `index.html` — article content, metadata, and JSON-LD structured data
- `styles.css` — responsive visual styling

## Publish with GitHub Pages
1. Create a GitHub repository. For a personal site, the repository can be named `YOUR-GITHUB-USERNAME.github.io`; otherwise use any repository name.
2. Upload `index.html` and `styles.css` to the repository's root folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. After GitHub Pages publishes the site, open the provided Pages URL to verify it.

## Important: update the canonical URL
In `index.html`, replace each occurrence of:
`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY/`
with your actual published GitHub Pages URL. Update both the `<link rel="canonical">`, Open Graph URL, and the `@id` inside the Article JSON-LD.
